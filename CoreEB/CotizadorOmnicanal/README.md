# Cotizador Omnicanal

Este proyecto busca desarrollar una herramienta que centralice la cotización de servicios omnicanal para clientes de Core EB.

**Objetivos:**
- Unificar cotizaciones de WhatsApp, Call Center y Chatbots.
- Facilitar el cálculo automático de costos operativos.
- Optimizar tiempos de respuesta comercial.

**Ideas iniciales:**
- Interfaz simple donde se ingresan datos del cliente y tipo de servicio.
- Resultado: valor estimado, desglose por canal y margen sugerido.
- Integración futura con CRM o base de datos de clientes.
